# 屿间

屿间是一个文化旅行展示网站，通过大同的地图、影像与旅行手记，呈现一路上的地方生活。

[访问屿间官网](https://pualweal-tech.github.io/-/)

## 本地开发和发布

使用 Node.js 22，在项目目录运行 `npm ci` 安装依赖，然后运行 `npm run dev`。本地预览地址为 <http://localhost:4180/>。

运行 `npm run build` 可检查 TypeScript 并生成静态站点。推送到 `main` 后，GitHub Actions 会自动构建并发布到 GitHub Pages。

## 本轮行为

- 全中文导航与正文；寺庙古城、树木的首屏背景，主文案和手机轻量入场。
- 首屏手机向前倾、只显示约一半；继续滚动后移动至左侧。
- 同一台手机内显示卫星地图。大同、云冈区、浑源三个节点与底图共享坐标系，三个端点均可看见；行程卡片上滑弹出。
- 地图过渡成旅行手记，三张照片便签浮出手机；右侧三段规划文案依次滚出，第二段时手机轻微右移。
- 进入灰绿蓝暗色画面，手机移动到右侧；四段中文文案与照片短片随滚动切换。进度条随滚动推进，播放键可播放当前照片的缓慢推进效果，继续滚动会回到滚动控制。
- 七台文化旅行手机从中心散开、轻微浮动，再缩入下方纸质旅行画册；四张人物照片依次弹出。向上滚动可逆向恢复。
- 人物照片可点击看大图；弹窗支持 Esc、关闭按钮、背景关闭与焦点恢复。
- 产品细节包含三档可见范围预览、入视充电、地方文化精选和中文常见问题。所有页面内导航均有实际目标。

交互跟随页面真实滚动距离，不统计滚轮事件次数，不拦截滚轮。鼠标、触控板、键盘、滚动条均可驱动；右侧章节按钮可直接跳转。每段约保留一屏阅读距离，大幅滚动可跨越段落。

宽度小于 900px，或系统选择“减少动态效果”时，主叙事与相册使用普通流式布局，内容保持可读。

## 修改入口

- `src/components/UnifiedScrollytelling.tsx`：首屏、手机位移、三段规划和四段影像的分镜。
- `src/components/Phone.tsx`：手机壳、地图、行程弹层、便签屏幕和短片播放器。
- `src/useSectionProgress.ts`：原生滚动进度，所有联动共用一个来源。
- `src/data.ts`：主叙事照片与文案。
- `src/components/SevenPhonesAndAlbum.tsx`、`album.css`：七机与画册。
- `src/components/BentoGrid.tsx`、`Footer.tsx`、`Details.css`：产品细节与页脚。
- `src/components/Navbar.tsx`、`src/App.tsx`：导航与体验弹窗。
- `src/index.css`：全局排版、手机、主叙事与响应式样式。
- `public/assets`：工程内相对引用的照片和品牌标记，不依赖原素材库的绝对路径。

副本中仍保留部分未挂载的原参考组件，当前页面以 `App.tsx` 的导入为准。

## 当前展示范围

这是官网交互原型。照片短片依照需求以图片代替视频；路线是行程示例。账号、真实客户端安装、实际导航、上传、旅行书下单和后台分享权限均未接入。页面已移除虚构机构、奖项、备案号及功耗数字。

测试细节见 `测试记录/测试报告.md`；图片对应见 `素材使用说明.md`。
